# 让你花个爽！

一个帮助用户缓冲消费冲动的全景房间交互原型。小浣熊作为主 IP 带用户进入同一个全景房间；用户随后可以拖动环视，与健身屏、茶几手机、预算白板和快递箱互动，记录消费欲望、处理冷静订单、查看钱包病历和推进预算目标。AI 的解释与反馈仍由钱包病历本诊疗终端承担。

## 当前能力

- 基于 2:1 场景图的轻量 WebGL 球形全景、拖动环视和滚轮缩放
- 约 3 秒不可跳过的原创像素瀑布开屏、主 IP 入口定格与同场景镜头拉远
- 配置驱动的热点注册表；当前包含健身屏、茶几手机、白板和 5 个快递箱热点
- 点击物件后的镜头聚焦、发光提示和内容面板
- 云下单、订单状态、确认省下金额和回血目标闭环
- 基于本地消费行为的五维评分、四类动机、主 / 副人格和置信度
- DeepSeek 结构化复诊、数据发送确认、超时 / 错误降级和结果过期联动
- 浏览器本地存储、演示数据和 JSON 导出
- 桌面、平板和手机响应式布局
- 键盘操作、焦点恢复与减少动态模式
- WebGL 或场景图片失败时仍保留文字导航和业务面板

早期 CSS「钱包兽」占位已由用户提供的小浣熊主 IP 替换。小浣熊负责入口和空间引导，不负责决定消费人格、分数或 AI 结果。

原始场景图保留为 `图片 3.png`；本轮高清房间原图位于 `视觉包2/小浣熊坐脚凳玩手机_高清版.jpg`，浏览器加载其 8192×4096 派生 WebP，并由渲染器按设备纹理上限自动降采样。

## 本地运行

项目不依赖构建工具。只看本地评分时，可以启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

需要验证 DeepSeek 时，使用 Node 20 及以上版本启动同源服务：

```bash
export DEEPSEEK_API_KEY="你的服务器密钥"
npm start
```

然后访问 <http://127.0.0.1:8787>。可选环境变量见 [`.env.example`](./.env.example)。密钥只应配置在服务端环境中，不要写入任何前端文件。

## 数据与 AI 边界

- 当前订单、目标与诊断结果只保存在用户浏览器中。
- 项目不会发起真实支付，也不连接银行卡或支付账户。
- 钱包病历本始终先在浏览器本地计算确定性分数，DeepSeek 只解释结果，不能改写分数和人格。
- 用户明确同意后才发送选定周期的聚合统计、本地评分和证据目录；不发送商品名称、备注或订单 ID。
- 没有密钥、超时、限流或 DeepSeek 输出无效时，页面明确标记本地降级，本地评分和其他业务继续可用。

## 阿里云部署

生产环境统一使用短英文标识 `spree`：

- 服务器目录：`/home/spree`
- 容器名：`spree`
- 域名：`https://spree.jamson.top`
- 密钥文件：`/home/spree/.env`，仅 root 可读

首次部署时，在服务器复制环境变量模板并填写真实密钥：

```bash
cd /home/spree
cp deploy/spree.env.example .env
chmod 600 .env
docker compose -p spree up -d --build
```

Compose 只把服务映射到宿主机 `127.0.0.1:8787`，公网流量由 Caddy 接收。容器使用非 root 用户、只读文件系统、移除 capabilities，并限制内存、CPU、进程数和日志大小。完整拓扑、密钥边界和回滚方式见 [`Spree 生产部署方案`](./docs/plans/2026-08-26-spree-production-deployment.md)。

健康检查：`GET /api/health`。它只返回服务状态、模型名和是否已配置密钥，不返回密钥内容。
