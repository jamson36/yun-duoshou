# 云剁手

一个帮助用户缓冲消费冲动的 2.5D 房间交互原型。用户可以在房间中与主 IP「钱包兽 01」以及四件功能物品互动，记录消费欲望、处理冷静订单、查看钱包病历和推进回血目标。

## 当前能力

- 2.5D 钱包房间、主 IP 与四件可交互物品
- 点击物件后的镜头聚焦、放大转场和内容面板
- 云下单、订单状态、确认省下金额和回血目标闭环
- 基于本地消费记录的钱包病历交互原型
- 浏览器本地存储、演示数据和 JSON 导出
- 桌面、平板和手机响应式布局
- 键盘操作、焦点恢复与减少动态模式

## 本地运行

项目不依赖构建工具。在项目目录启动一个静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

## 数据与 AI 边界

- 当前订单、目标与诊断结果只保存在用户浏览器中。
- 项目不会发起真实支付，也不连接银行卡或支付账户。
- 钱包病历本目前是确定性的本地交互原型，尚未接入真实 AI 模型。
- 后续接入 AI 时，只应发送经过用户确认的汇总数据，不发送完整单笔消费记录。
