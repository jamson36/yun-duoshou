# 欲望剥壳机素材清单 v1

首发版不加载第三方图片或外部字体。商品、贴纸、封条、刀锋、碎屑和冷静篮均由项目内 Canvas 程序化绘制，并由语义化 DOM 承担文字与操作。

| 视觉层 | 作者方式 | 逻辑尺寸 | 用途 | 降级 |
|---|---|---:|---|---|
| 11 类商品本体 | 项目内 Canvas 基础几何与系统图形组合 | 96×96 | 抛出后始终完整的商品核心 | CSS 文字降级显示商品名 |
| 单层话术贴纸 | 项目内圆角矩形与折角程序化绘制 | 168×68 | 显示一层“话术样本” | 语义目标按钮显示外壳短句 |
| 双层话术贴纸 | 同一绘制器以颜色和偏移组合 | 176×74 | 仅用于审核过的两层组合 | 按外层到内层逐次显示 |
| 外壳碎屑 | 命中点生成的小型几何片段 | 最大 18×18 | 短时剥落反馈 | 减少动态或低性能时不显示 |
| 冷静篮与光圈 | Canvas 线条、渐变与 CSS | 舞台宽度自适应 | 商品剥净后的柔和落点提示 | 状态区播报“商品完整保留” |

所有绘制都不依赖文件名推断规则；商品、外壳和局内状态由 `peel-game.js` 的显式数据结构控制。Canvas 不可用时启用 CSS 文字降级，仍可用持久目标控制器完成一局。
