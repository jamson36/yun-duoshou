# 切一刀素材清单

- `warm-room.png`：用户提供的 Grid.png，作为暖色房间背景，原图保留。
- `basket.svg`：项目内原创 SVG，参考用户第三张图的俯视角度绘制红色网格购物篮。
- `sticker-preview.svg`：项目内原创 SVG 奶茶、耳机和相机贴纸，参考第二张图的彩色与白边风格，未复制品牌标识。
- 游戏内 11 种商品由 `peel-product-visuals.js` 使用 Canvas 程序化绘制。切中后同一商品按左右两半裁切并短暂飞散；低性能或减少动态时保留静态商品和文字反馈。
- Canvas 不可用时采用 CSS 文字降级与语义目标按钮；鼠标、触屏、键盘和主动开启的本地摄像头手势共享命中逻辑。

资源均由本项目同源加载，不依赖外部字体或图片服务。
