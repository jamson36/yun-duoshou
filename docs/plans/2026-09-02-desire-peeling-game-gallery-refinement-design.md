# 欲望剥壳机「精品解构舱」视觉重构设计

日期：2026-09-02
状态：用户已选择方案 A，可进入实现
范围：只重构欲望剥壳机的视觉表达与反馈，不改变订单、评分、目标、路由和摄像头隐私边界

## 1. 核心判断

当前版本的问题不是配色不够丰富，而是视觉隐喻过于字面：商品本体是一张带 Emoji 的方卡，促销话术又是一张覆盖其上的彩色纸牌，切开后继续出现黑色文字卡。三层都以“卡片”表达，用户看到的是叠放的 UI 组件，而不是正在被剥离的消费推动力；粗描边、硬阴影、米色网格与高饱和色同时出现，也让体验更像功能 Demo 或儿童街机。

重构采用“精品买手店里的玻璃解构舱”。商品以克制的矢量线稿和材质高光悬浮在暗色玻璃空间中，是画面唯一实体。促销话术不再是硬壳或贴纸，而是绕商品旋转的半透明信号膜：细线轨道承担“环绕”，短关键词承担“干扰”，微弱色散承担“营销气氛”。划过之后，信号膜沿刀锋方向分离为薄片和光尘，完整商品被柔光照亮。完整反思话术只作为一秒左右的低声“回声”浮现，不制造新的卡片。

## 2. 视觉语言

- 基底：烟黑、暖灰和象牙白，延续房间暗色世界观；荧光青柠只用于可操作状态和切割瞬间。
- 商品：不再绘制 Emoji 方卡。使用按商品类型区分的矢量轮廓、局部填充和高光，名称以小字号陈列标签置于下方；真实订单有金额时才显示金额。
- 信号膜：使用半透明圆角薄膜、细边和轨道弧线。画面只呈现 `限时`、`都在买` 等短诱因，不显示“话术样本”等解释性标签。
- 刀锋：从“准星加白棍”改为轻量光标和带衰减的切割光轨；触摸、鼠标和体感共享同一反馈。
- 空间：去除点阵游戏底板和实体“冷静篮”，底部改为一条展台地平线，文案为“决定权留在你手里”。
- 排版：标题保持品牌力量感，说明文字减少密度；数值、阶段和状态采用展签式小型排版，不再使用夸张街机计分牌。

## 3. 三个界面状态

### 3.1 进入页

右侧主视觉改为玻璃舱：线稿耳机悬浮在中心，两层信号膜以不同深度环绕，切割光线从前景掠过。规则压缩为三条无边框步骤，主要按钮取消厚重黑色投影。用户第一眼应理解“去掉外界推动，留下商品”，而不是“打碎写字卡片”。

### 3.2 游戏中

舞台为带柔和聚光和细微噪点的暗色玻璃空间。商品从底部抛起，轮廓和信号膜在运动中保持清晰；同屏商品仍不超过八个。未切信号膜显示短诱因，切开时产生有限的薄片、字符残影和光尘；商品完全显露后只增加一圈柔光，不允许继续切碎。教程、暂停和语义控制器继续使用真实 DOM，但视觉收敛为展签和工具条。

### 3.3 结算页

取消紫色巨型分数牌，改为编辑式双栏：左侧用小型环形刻度展示本局识别层数，右侧完成“哪句话最会推你”选择和冷静提醒。选择胶囊使用细边与轻填充，不再使用卡通阴影。焦点商品只显示名称和通用陈列标记；“放进冷静区”仍只打开预填表单，不直接生成订单。

## 4. 动效与无障碍

- 常规模式：信号膜可以轻微呼吸和错层漂移；切割反馈控制在约 650ms，反思回声控制在约 1250ms。
- 减少动态：取消漂移、旋转、碎片飞散和循环呼吸，仅保留静态膜消失、商品高亮与文字回声。
- Canvas 只负责装饰与运动。现有动态目标语义控制器、方向键、Enter / Space、触控和屏幕阅读器播报继续有效。
- Canvas 不可用时继续显示 DOM 目标列表；视觉重构不得把可访问性回退隐藏在 Canvas 内。
- 摄像头只在用户主动选择体感后启用，帧仍仅进入本地 Worker；体感轨迹不能触发“放进冷静区”等业务动作。

## 5. 验收标准

1. 游戏画面不再出现 Emoji 商品方卡、“话术样本”标签、实心纸牌外壳、点阵底板或实体冷静篮。
2. 至少五类商品拥有可辨识的矢量轮廓，其余商品使用一致的通用精品陈列轮廓，不能回退为 Emoji。
3. 短诱因仍能在运动中阅读，但商品视觉面积明显大于文字面积。
4. 切开时先消失信号膜，再高亮商品；反思句不是新的实心卡片。
5. 桌面 1440×1000、平板 768px、移动端 390×844 无溢出和遮挡。
6. 鼠标、触摸、键盘和体感映射保持原有行为；减少动态和 Canvas 失败回退通过。
7. 自动化测试、语法检查、Compose 配置与 `git diff --check` 通过；浏览器截图由实现后重新生成，不复用旧版证据。
