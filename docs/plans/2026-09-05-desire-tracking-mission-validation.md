## 已实现

真实掌机入口 → 连续夜城追踪 → 甩开两层广告外壳 → 七天轨道 / 已有替代 / 目标天平拖放 → 冷静传送带 → 明确确认保存 → 返回房间。耳机是本轮完整可玩任务；用户追加的 WASD 与鼠标方向控制及最新验证见文末。

普通操作支持鼠标、触摸和键盘。手势只操作当前任务，进入确认页后停止摄像头输入，保存须由用户点击。使用说明中提供由热点注册表派生的文字入口，减少动态或无法环视时仍可进入。

## 追加：WASD 移动与鼠标视角（2026-09-05）

依据用户追加要求，追踪阶段改为按住 W/S 前后、A/D 左右，方向键同义，松键立即停止。按住空白街景拖动鼠标调整视角，W 的移动方向随相机朝向变化。路标仍可点击或用 Tab / Enter 自动前往，途中可以按键接管；接近三个路标后依次推进到商品工作台。移动限制在街道内，后续商品拖放与确认保存继续沿用原合同。

失焦、页面隐藏、关闭、切换手势和进入工作台均清除按键，过期重复按键不恢复行走。输入框中 WASD 正常输入文字。短屏路标按实际标题、按钮和页脚尺寸避让；触摸拖动后的键盘点击不会被误拦截。入口及内部模块缓存版本统一为 `20260905-mission-wasd-2`。
