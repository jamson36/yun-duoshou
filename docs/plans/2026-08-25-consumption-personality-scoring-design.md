# 让你花个爽！消费人格与 AI 评分机制设计

> 版本：v1.0-draft
> 日期：2026-08-25
> 适用范围：让你花个爽！消费记录、分析页及后续 AI 消费洞察
> 性质：产品与算法设计稿，不是心理测验或财务诊断
> 与当前 PRD 的关系：作为分析页与未来 AI 能力的配套设计；不直接改写已冻结 PRD

## 0. 核心结论

让你花个爽！不应再用“30 天内最高频消费品类”直接判断消费人格。品类只能说明用户最近把钱花在什么地方，不能说明他为什么买、如何决策、是否容易冲动。

推荐采用四层结果：

1. **五个消费决策维度**：即时冲动、价格敏感、研究验证、外部依赖、情绪体验。
2. **四类购买动机**：掌控、疗愈、成就、认同。
3. **行为结果指标**：冷静成功率、购买转化率、决策时长、反复率。
4. **人格与主题表达**：输出一个主人格、必要时一个副人格；原有“奶茶股东型选手”等改为钱包主题标签。

AI 不直接“凭感觉打分”。AI 只负责把备注等自然语言整理成带置信度的结构化证据，以及把确定性评分结果写成用户看得懂的解释。最终分数由本地、可复算的规则引擎产生。

## 1. 七篇参考帖的内容梳理

### 1.1 来源一：ATM / ACCT / Killer / FAWO / VIP

原帖：<https://www.xiaohongshu.com/explore/6a059f7c0000000007022f44>

| 帖中类型 | 核心特征 | 判断理由 | 可用于本项目的部分 | 限制 |
| --- | --- | --- | --- | --- |
| ATM 买买买型 | 喜欢就下单，尽量不犹豫 | 即时满足高于延迟决策 | 即时冲动 | 偏娱乐化，缺少严谨量表 |
| ACCT 精算理财型 | 反复计算满减与最优组合 | 对价格规则、优惠差额高度敏感 | 价格敏感、研究验证 | “爱优惠”不等于“少花钱” |
| Killer 薅羊毛型 | 找券、砍价、追求低价或免费 | 愿意投入额外时间换取价格优势 | 价格敏感、外部协作 | 可能因凑单反而多消费 |
| FAWO 求链接型 | 看见他人购买后索要链接 | 购买线索明显来自他人 | 外部依赖、种草来源 | 只靠社交来源不能判断冲动程度 |
| VIP 会员型 | 围绕会员权益形成消费 | 愿意为持续权益或身份付费 | 会员/权益主题标签 | 更像营销权益，不是独立人格 |

评论区有大量“精打细算但也爱买”的混合自述，说明单标签很容易失真。该帖适合作为趣味命名来源，不适合作为完整评分依据。

### 1.2 来源二：五类购买动机

原帖：<https://www.xiaohongshu.com/explore/695ca794000000001a0206f6>

| 类型 | 本质上为什么买 | 常见证据 | 容易误判的地方 |
| --- | --- | --- | --- |
| 精明主权者 | 为掌控感买单 | 看重耐用、性价比、秩序、长期使用和可流转 | 比价不一定是缺钱，也可能是追求确定性 |
| 感官疗愈师 | 为疗愈感买单 | 舒适、香氛、睡眠、氛围、即时情绪修复 | 体验消费不必然等于不理性 |
| 微观成就家 | 为成就感买单 | 课程、工具、兴趣、技能提升、完成作品 | 购买课程不等于真的学习，需要区分购买与使用 |
| 价值共鸣者 | 为认同感买单 | 品牌故事、文化周边、价值观、小众设计 | 认同品牌不等于依赖社交评价 |
| 平衡洞察者 | 根据情境综合决策 | 不被单一动机长期支配，品类和决策方式较均衡 | 不能在数据不足时把“看不出来”包装成平衡 |

这组内容最适合作为**动机层**，不宜直接替代行为维度。一个用户可以同时“高研究验证”且“为疗愈买单”。

### 1.8 综合可信度分级

| 证据层 | 说明 | 本设计的使用方式 |
| --- | --- | --- |
| A：直接行为 | 决策时长、是否比价、是否询问、最后买没买 | 主要计分证据 |
| B：结构化自述 | 触发原因、决策动作、购买动机 | 辅助计分证据 |
| C：自然语言推断 | 备注中的情绪、品牌故事、使用计划 | AI 提取，降权使用 |
| D：品类/人群代理 | 从类别猜测动机、身份或性格 | 只作主题标签，原则上不计人格分 |

七篇帖子都是产品灵感，不构成经公开验证的心理量表。让你花个爽！的结果文案必须使用“最近的消费倾向”“从现有记录看”，不能使用“科学证明你是”或“诊断结果”。

## 2. 方案比较与选择

### 方案 A：按最高频品类给人格

- 优点：实现最简单，3 条记录也能出结果。
- 缺点：把“买了什么”误当成“为什么买”；同一人换一个月份就可能完全变人格。
- 结论：保留为趣味的“钱包主题”，不再叫核心人格。

### 方案 B：复刻 16 型字母代码

- 优点：传播性强，结果看起来完整。
- 缺点：参考帖子未公开算法；当前订单字段不足以支持 16 种稳定区分；字母代码会制造虚假精确感。
- 结论：不采用。

### 方案 C：连续维度 + 动机 + 主副人格

- 优点：能处理混合人格；每一分都有证据；可随行为更新；可区分“情绪买单”和“冲动下单”；适合 AI 解释。
- 缺点：需要增加少量决策动作字段，并设计置信度。
- 结论：**推荐并采用。**

## 3. 总体模型

```text
订单事实 + 结构化原因 + 决策动作 + 可选备注
                    │
                    ▼
            证据标准化与可靠性分级
                    │
          ┌─────────┼─────────┐
          ▼         ▼         ▼
       五维评分   四类动机   行为结果
          └─────────┼─────────┘
                    ▼
          主人格 / 副人格 / 主题标签
                    │
                    ▼
            AI 生成证据化解释与建议
```

结果需要回答五个不同问题：

1. 用户通常多快做决定？
2. 用户多在意价格规则与优惠？
3. 用户会做多少研究和验证？
4. 用户多依赖评价、达人、朋友或群体？
5. 用户多在意疗愈、氛围和情绪体验？

这些问题不能互相替代。例如“优惠精算师”可能依然高冲动；“感官疗愈师”也可能研究充分后再购买。

## 4. 五个核心维度

每个维度为 0–100 分，50 表示当前证据总体中性。低分不是差，高分也不是好，只代表近期决策风格。

| 代码 | 维度 | 低分含义 | 高分含义 | 主要直接证据 |
| --- | --- | --- | --- | --- |
| I | 即时冲动 | 延迟决定、愿意冷静 | 触发后快速行动 | 决策时长、直接下单、被种草、限时优惠 |
| P | 价格敏感 | 较少关注价格规则 | 主动比价、找券、凑满减 | 比价、领券、满减、价格备注 |
| R | 研究验证 | 直觉或省事优先 | 查参数、看差评、多方比较 | 查参数、看评测、看差评、等待验证 |
| X | 外部依赖 | 主要自己判断 | 明显依赖达人、朋友、评价和圈层 | 来源、问朋友、看达人、买家评价、社交需要 |
| E | 情绪体验 | 功能和任务优先 | 疗愈、氛围、悦己和感官体验优先 | 情绪不好、无聊、嘴馋、氛围/舒适动作 |

### 4.1 不作为核心维度的内容

- **消费品类**：只生成钱包主题。
- **花钱多少**：只调整单条证据的重要度，不能直接判断人格。
- **年龄、性别、地域、收入和社会身份**：不从消费行为推断。
- **是否最终购买**：主要属于行为结果；只能给冲动维度极弱的辅助证据，避免把合理购买误判为冲动。
- **是否节俭**：需要结合长期预算与可支配收入，当前项目没有这些数据，不能下结论。

## 5. 四类购买动机

动机不是 0–100 的互斥标签，而是四项占比，总和为 100%。

| 动机 | 含义 | 高权重证据 |
| --- | --- | --- |
| 掌控 Control | 为秩序、耐用、确定性、性价比和长期使用买单 | 比价、长期使用、耐用、二手流转、计划内需求 |
| 疗愈 Healing | 为舒适、放松、仪式感和情绪修复买单 | 情绪不好、无聊、嘴馋、悦己、氛围、睡眠 |
| 成就 Achievement | 为技能、工具、兴趣进展和完成感买单 | 自我提升、课程、专业工具、作品计划 |
| 认同 Identity | 为品牌价值、故事、文化圈层和身份表达买单 | 社交需要、品牌故事、文化周边、价值观一致 |

当第一、第二动机占比差小于 12 个百分点时，显示“双动机”；四项相对均衡且数据充分时，才显示“复合动机”。

## 6. 行为结果指标

这些指标描述产品是否帮助用户获得冷静空间，不参与道德评价。

| 指标 | 公式 | 展示方式 |
| --- | --- | --- |
| 冷静单数率 | 幸好没买单数 ÷ 已做决定单数 | “本期有 58% 的欲望在冷静后放下” |
| 冷静金额率 | 幸好没买金额 ÷ 已做决定总金额 | “放下的金额占 63%” |
| 购买转化率 | 最终购买单数 ÷ 已做决定单数 | 与冷静率并列展示，不称为失败率 |
| 中位决策时长 | `decidedAt - createdAt` 的中位数 | “你通常会给自己 18 小时” |
| 决策反复率 | 发生过状态改写的订单 ÷ 已做决定单数 | 需要状态历史，表示犹豫程度 |
| 待冷静率 | 冷静中订单 ÷ 全部有效订单 | 帮助提醒，而非人格评分 |

删除订单、演示数据和无有效金额的记录不参与统计。状态改写后必须全量重算当前周期。

## 7. 所需数据与最小改造

### 7.1 现有字段可继续使用

```ts
type Order = {
  id: string
  name: string
  amount: number
  category: string
  reason: string
  note?: string
  status: 'cooling' | 'saved' | 'purchased'
  createdAt: string
  updatedAt: string
}
```

### 7.2 推荐新增字段

```ts
type ConsumptionEvidenceV1 = {
  triggerReasons: string[]
  decisionSignals: string[]
  source?: 'self_need' | 'ad' | 'creator' | 'friend' | 'review' | 'promotion' | 'other'
  decidedAt?: string
  statusHistory?: Array<{
    from: 'cooling' | 'saved' | 'purchased'
    to: 'cooling' | 'saved' | 'purchased'
    at: string
  }>
  isDemo?: boolean
}
```

推荐的 `decisionSignals` 选项：

- 没做功课直接想下单
- 等一晚再决定
- 比过价格
- 查过参数或成分
- 看过买家评价或差评
- 问过朋友
- 看了达人或直播推荐
- 找券或凑满减
- 主要为了舒适或氛围
- 主要为了学习或完成作品
- 主要认同品牌故事或价值观
- 家里已有同类仍想囤

录单时仍以轻量为主：保留一个必选触发原因，最多展示两个可选决策动作，不做 28 道题式问卷。用户可以在后续决定订单状态时补充动作。

### 7.3 字段迁移

- 旧 `reason` 迁移为 `triggerReasons[0]`。
- 没有 `decidedAt` 的旧订单，不使用 `updatedAt` 猜决策时长，因为 `updatedAt` 也可能只是修改名称或备注。
- 没有新增证据的旧订单仍可生成钱包主题和低置信度倾向，但不能强行生成“研究验证”等无依据分数。

| 看过买家评价或差评 | -0.1 | 0 | +0.8 | +0.5 | 0 | 掌控 +0.2 |
| 问过朋友 | 0 | 0 | +0.3 | +1.0 | 0 | 认同 +0.2 |
| 看了达人或直播推荐 | +0.4 | 0 | 0 | +1.0 | +0.2 | 认同 +0.3 |
| 找券或凑满减 | +0.2 | +1.0 | +0.3 | 0 | 0 | 掌控 +0.3 |
| 主要为了舒适或氛围 | +0.2 | 0 | 0 | 0 | +1.0 | 疗愈 +1.0 |
| 主要为了学习或完成作品 | 0 | 0 | +0.3 | 0 | 0 | 成就 +1.0 |
| 认同品牌故事或价值观 | 0 | 0 | 0 | +0.3 | +0.2 | 认同 +1.0 |
| 家里已有同类仍想囤 | +0.5 | +0.2 | -0.2 | 0 | +0.2 | 收藏囤货直接证据 |

### 8.3 决策时长对即时冲动的贡献

| `decidedAt - createdAt` | I 贡献 |
| --- | ---: |
| 小于 10 分钟 | +1.0 |
| 10 分钟至 2 小时 | +0.6 |
| 2 小时至 24 小时 | +0.2 |
| 1 至 3 天 | -0.4 |
| 3 天及以上 | -0.8 |

演示数据和用户明确标记为“补录”的历史订单不使用此规则。

### 8.4 证据可靠性

| 证据来源 | 可靠性系数 |
| --- | ---: |
| 真实时间与状态历史 | 1.00 |
| 用户主动选择的决策动作 | 1.00 |
| 用户选择的触发原因 | 0.90 |
| 用户主动填写的动机小问 | 0.80 |
| AI 从备注提取，模型置信度 ≥ 0.70 | 最高 0.50，再乘模型置信度 |
| 品类代理 | 最高 0.20，且只建议用于主题/动机弱证据 |

AI 提取置信度低于 0.70 时只生成解释候选，不进入分数。

## 9. 计算公式

### 9.1 单条证据权重

```text
w(e) = reliability(e)
     × recency(e)
     × amountModifier(e)
     × extractionConfidence(e)
     × validMask(e)
```

其中：

```text
recency = 0.5 ^ (ageDays / 14)
```

14 天为半衰期，30 天为主展示窗口。超过 90 天的证据不进入当前人格，只进入长期趋势。

金额修正仅表示该欲望对用户本期钱包的影响，不直接把高价等同于冲动：

```text
amountModifier = clamp(sqrt(amount / personalMedianAmount), 0.75, 1.50)
```

- 有效订单少于 5 条时，`amountModifier = 1.00`。
- `validMask`：有效真实订单为 1；删除、演示、金额非法的记录为 0。

### 9.2 维度分数

每条证据在每个维度上有 `direction ∈ [-1, 1]`。计算某个维度时，只纳入该维度上 `direction ≠ 0` 的证据，避免无关记录把分数机械稀释回 50：

```text
axisRaw = Σ(w(e) × direction(e)) / Σw(e)
axisScore = round(clamp(50 + 50 × axisRaw, 0, 100))
```

若某个维度没有任何直接或结构化证据，则返回 `null`，前端显示“证据不足”，不能用 50 冒充真实中立。

### 9.3 动机占比

对每类动机累积非负证据，并使用 0.5 的平滑项避免小样本极端化：

```text
motivationWeight(k) = 0.5 + Σ(w(e) × motivationContribution(e, k))
motivationShare(k) = motivationWeight(k) / Σ motivationWeight(all)
```

### 9.4 行为结果

行为结果只使用已经明确进入 `saved` 或 `purchased` 的订单。`cooling` 不进入分母。

```text
savedCountRate = savedCount / decidedCount
savedAmountRate = savedAmount / decidedAmount
purchaseRate = purchasedCount / decidedCount
reversalRate = ordersWithStatusReversal / decidedCount
```

## 10. 人格库与匹配规则

### 10.1 通用函数

```text
high(s) = clamp((s - 50) / 50, 0, 1)
low(s)  = clamp((50 - s) / 50, 0, 1)
```

动机占比和各类事件比率本身为 0–1。

### 10.2 九类人格

#### 1. 研究主权者

- 判断内核：靠研究和自主判断获得掌控感。
- 主要证据：高 R、低 I、掌控动机高、外部依赖不高。
- 初始匹配：`100 × (0.35×high(R) + 0.20×low(I) + 0.25×Control + 0.10×low(X) + 0.10×researchEventRate)`。
- 最少条件：至少 2 条直接研究证据。
- 不能仅因“数码家居”品类判定。

#### 2. 优惠精算师

- 判断内核：愿意拆解价格规则，用时间换价格优势。
- 主要证据：高 P、高 R、比价/券/满减动作。
- 初始匹配：`100 × (0.40×high(P) + 0.20×high(R) + 0.25×dealEventRate + 0.15×Control)`。
- 最少条件：至少 2 条优惠或比价直接证据。
- 解释必须同时提示“省到”和“为优惠多买”的可能性，不能默认其总支出更低。

#### 3. 种草冲锋手

- 判断内核：外部种草很容易缩短决策时间。
- 主要证据：高 I、高 X、被种草/达人/直播来源。
- 初始匹配：`100 × (0.30×high(I) + 0.25×high(X) + 0.15×high(E) + 0.30×seededEventRate)`。
- 最少条件：至少 2 条种草或外部来源直接证据。

#### 4. 氛围疗愈师

- 判断内核：消费主要承担情绪修复、舒适和仪式感功能。
- 主要证据：高 E、疗愈动机高、情绪/无聊/氛围事件多。
- 初始匹配：`100 × (0.30×high(E) + 0.35×Healing + 0.25×healingEventRate + 0.10×high(I))`。
- 最少条件：至少 2 条情绪或体验直接证据。
- 不能把疗愈消费自动写成“不理性”。

#### 5. 社交共鸣者

- 判断内核：朋友、圈层、评价和价值认同明显参与购买决策。
- 主要证据：高 X、认同动机高、社交/品牌故事事件。
- 初始匹配：`100 × (0.30×high(X) + 0.35×Identity + 0.25×identityEventRate + 0.10×high(E))`。
- 最少条件：至少 2 条社交、评价或价值认同直接证据。

#### 6. 微观成就家

- 判断内核：消费服务于技能、工具、兴趣进展或具体作品。
- 主要证据：成就动机高、自我提升/工具动作、适度研究。
- 初始匹配：`100 × (0.45×Achievement + 0.20×high(R) + 0.25×achievementEventRate + 0.10×learningThemeShare)`。
- 最少条件：至少 2 条自我提升、技能或作品直接证据。
- 学习成长品类只能提供弱证据，不能单独判定。

#### 7. 极简缓冲者

- 判断内核：倾向给欲望留出时间，最后主动放下非必要购买。
- 主要证据：低 I、等待动作多、冷静金额率高、掌控动机较高。
- 初始匹配：`100 × (0.20×low(I) + 0.20×waitEventRate + 0.30×savedAmountRate + 0.15×Control + 0.15×low(E))`。
- 最少条件：至少 3 个已决定订单，且至少 2 个为冷静后放下。
- 不称为“更高级”或“更自律”，避免道德化。

#### 8. 收藏囤货派

- 判断内核：对拥有、完整收集或未来备用的需求高于即时使用需求。
- 主要证据：明确囤货动作、短期重复同类购买、已有同类仍购买。
- 初始匹配：`100 × (0.35×stockEventRate + 0.20×repeatPurchaseRate + 0.15×purchaseRate + 0.15×high(I) + 0.15×high(P))`。
- 硬门槛：至少 2 条显式囤货或重复购买证据；没有该证据时不得输出。
- 不能仅凭购物车数量或单一大额订单判断。

#### 9. 平衡洞察者

- 判断内核：不同情境使用不同策略，没有单一维度长期支配。
- 主要证据：维度差异小、四类动机分布较均衡、品类多样且数据充分。
- 初始匹配：`100 × (0.40×axisBalance + 0.30×motivationEntropy + 0.20×categoryDiversity + 0.10×decisionStability)`。
- 硬门槛：至少 8 个有效订单、置信度不低于 60，且五维中至少 4 维有直接证据。
- 数据不足时必须写“尚未形成稳定画像”，不能用“平衡”兜底。

### 10.3 主人格与副人格

1. 先执行各人格的最少条件和硬门槛。
2. 对合格人格计算 `fitScore`。
3. 最高分至少 60，才输出主人格。
4. 第二名至少 55，且与第一名差值不超过 12，输出副人格。
5. 如果第一、第二名差值小于 5，文案显示“混合型”，两者并列，不制造虚假唯一性。
6. 没有任何人格达到 60 时，输出中性称号“欲望观察员”，同时说明还需要哪些证据。

人格匹配分不是心理量表百分位，也不能表述成“你比 82% 的人更冲动”。

| 最高频品类 | 钱包主题标签 |

| 其他 | 欲望观察员 |

建议结果页区分：

这样可以避免把四种不同概念挤成一个标签。

## 12. 置信度与出结果门槛

### 12.1 有效样本量

为避免大量相似证据虚增样本量，使用加权有效样本量：

```text
effectiveN = (Σw)^2 / Σ(w^2)
```

### 12.2 总置信度

```text
confidence = 100 × (
  0.40 × min(effectiveN / 12, 1)
  + 0.25 × directEvidenceShare
  + 0.20 × axisCoverage
  + 0.15 × min(activeDays / 14, 1)
)
```

- `directEvidenceShare`：直接行为与用户主动选择动作的权重占比。
- `axisCoverage`：有直接证据的维度数 ÷ 5。
- `activeDays`：首尾有效记录跨越天数。

### 12.3 展示等级

| 条件 | 展示结果 |
| --- | --- |
| 0–2 条有效订单 | 不出人格，只展示事实统计 |
| 3–4 条 | 可出“初步倾向”，必须显示低置信度 |
| 5–11 条且置信度 ≥ 45 | 输出“正在形成的人格画像” |
| 有效样本量 ≥ 12 且置信度 ≥ 70 | 输出“相对稳定的近期画像” |
| 任意数量但关键维度无证据 | 相关维度显示“证据不足” |

这与当前 PRD 的“至少 3 条”兼容：3 条仍能给用户反馈，但产品必须把它叫初步倾向，而非稳定人格。

## 13. AI 的职责边界

### 13.1 AI 可以做什么

1. 从用户备注中提取候选触发原因、决策动作和购买动机。
2. 给每个提取项返回原文证据、置信度和可否计分。
3. 基于规则引擎返回的分数生成解释。
4. 给出一条低压力、可执行、可撤销的建议。
5. 解释画像为什么变化，例如“最近两周被种草记录增加”。

### 13.2 AI 不可以做什么

1. 直接输出无法复算的总分或人格。
2. 用商品名称猜测年龄、性别、收入、疾病、家庭关系或社会阶层。
3. 把一次大额购买直接判成冲动。
4. 把“没有记录”当作“不存在”。
5. 使用羞辱、成瘾诊断或财务健康结论。
6. 为了让结果更有趣而编造用户没有提供的行为。

### 13.3 AI 结构化输出契约

```json
{
  "schemaVersion": "consumption-evidence-v1",
  "orderId": "local-order-id",
  "extractions": [
    {
      "signal": "watched_creator_recommendation",
      "source": "note_nlp",
      "evidenceText": "看直播间介绍后突然很想买",
      "modelConfidence": 0.87,
      "scoreEligible": true
    }
  ],
  "uncertainties": []
}
```

维度贡献必须从版本化证据字典读取，不能由模型自由生成。模型只选择 `signal`；规则引擎填入贡献值并计算最终结果。

## 14. 结果解释模板

结果页必须先说证据，再说判断，最后给行动建议。

### 14.1 推荐结构

```text
主人格：种草冲锋手
副人格：社交共鸣者

为什么这样判断：
最近 30 天，你有 5 次欲望来自种草、达人或朋友推荐；其中 3 次在 2 小时内做了决定。
这使你的“外部依赖”和“即时冲动”明显高于其他维度。

但这不是说你总会冲动：
你仍有 57% 的订单在冷静后选择了不买，说明缓冲动作正在起作用。

可以试试：
下次遇到种草订单，先保留链接并写下“如果 24 小时后还想要，它解决了什么问题”。

数据说明：
本期 9 条有效记录，画像置信度 63/100，研究验证方面证据较少。
```

### 14.2 文案禁区

- 禁止：“你就是冲动消费人格”“你有购物成瘾”“你的消费观有问题”。
- 推荐：“从最近 30 天的记录看”“这次结果更像一种近期倾向”“数据还少，先当作观察线索”。

## 15. 与当前产品阶段的落地顺序

### P0：不增加 AI、不改变本地隐私承诺

- 保持当前固定原因和本地存储。
- 将最高频品类结果从“消费人格”改称“钱包主题”。
- 用现有原因生成 I、X、E、P 的低置信度初步倾向；R 无证据时显示不足。
- 至少 3 条订单才显示初步倾向。
- 规则全部在前端本地运行。

### P1：增加轻量行为证据

- 增加 `decidedAt`、`decisionSignals`、`source`、`statusHistory`。
- 每次最多多选两个决策动作，避免录单负担。
- 上线五维雷达、四类动机、主副人格和置信度。
- 增加“为什么这样判断”的可展开证据列表。

### P2：引入 AI 辅助

- 默认只把去标识化的结构化特征交给 AI。
- 原始商品名与备注默认不离开本地；如需云端分析，必须单独说明、主动授权并支持撤回。
- AI 只做文本提取和解释，分数由版本化规则引擎计算。
- 每次画像保留 `modelVersion`、`featureVersion` 和评分快照，便于回放。

## 16. 校准与验收

### 16.1 上线前规则测试

至少覆盖：

1. **可复算性**：同一输入和同一规则版本必须得到同一结果。
2. **单调性**：增加一条高可靠的直接冲动证据，不应让 I 分下降。
3. **缺失安全**：没有 R 证据时返回 `null`，不能自动补成 50。
4. **状态修正**：幸好没买改为最终购买后，结果指标立即重算。
5. **演示隔离**：体验数据不进入真实画像。
6. **金额抗极端**：单条超大金额不能吞掉其余全部证据。
7. **门槛执行**：收藏囤货和平衡洞察者不能绕过硬门槛。
8. **来源约束**：AI 低置信度推断不得进入分数。
9. **人格稳定性**：增加一条中性记录不应造成完全不同的人格。
10. **隐私**：分享海报不包含商品名、备注原文和订单时间明细。

### 16.2 数据校准

v1 权重上线后，建议按以下顺序校准：

1. 收集用户主动选择的“这个结果像不像我”1–5 分反馈。
2. 记录用户认为判断错误的维度，但不记录敏感自由文本也可完成基础校准。
3. 以人工双人标注的行为证据作为对照，检查 AI 提取准确率。
4. 使用训练/验证分离的数据调整证据贡献与人格阈值。
5. 比较 7 天内重复评分的稳定性，避免人格随一条订单剧烈跳变。
6. 每次权重修改升级 `modelVersion`，旧画像可按旧版本回放。

在没有完成真实数据校准前，对外只能称“产品内消费倾向模型”，不能称“科学量表”或“心理学测评”。

### 16.3 产品验收标准

- 用户能看到每个主要判断对应的具体行为证据。
- 用户可以纠正触发原因、决策动作和状态，纠正后评分会更新。
- 数据少时明确提示不足，不强制生成精确人格。
- 同时展示积极解释和风险提醒，且不羞辱用户。
- 一个用户可以拥有主、副人格，不要求永久固定。
- 品类主题与行为人格在界面和数据结构中明确分离。
- AI 不可绕开规则引擎修改分数。

## 17. 最终产品口径

推荐对用户这样解释：

> 让你花个爽！会根据你最近记录的消费触发、决策动作和冷静结果，形成一份会变化的消费倾向画像。它不是心理诊断，也不评价你花钱对不对；它只是帮你看见，自己通常在什么情况下最容易想买，以及什么样的冷静方式对你更有效。

本机制的目标不是给用户贴一个终身标签，而是让每个分数都能回答：“这个判断是从哪些行为来的，我能不能纠正它，以及接下来可以尝试什么。”
