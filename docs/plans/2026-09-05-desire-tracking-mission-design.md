依据：会话 `01a060a6-88f9-7511-bf09-a27c696c422f` 于 2026-09-05 最后确认的方案，以及当前会话的实现授权。替代商品轮播与信号塔交互，保留既有工作树提交 `9e7d578` 为回退点。本轮仅本地实现。

## 体验与实现层级

从真实掌机进入一条连续的夜间街区，控制小浣熊探测器沿光路追踪广告；抓住并甩开耳机的两层营销外壳；把耳机放入一个试用装置；最后推入冷静传送带，经明确确认后保存冷静单。

选用轻量 Three.js 场景与语义 DOM 混合。纯 DOM 2.5D 难以呈现连续移动和镜头跟随。2026-09-05 用户追加“鼠标 WASD 控制方向”后，追踪阶段加入街道范围内的手动行走与鼠标视角；完整开放世界、角色模型和自由探索地图仍不在范围内。继续使用已有本地 Three.js 依赖，不新增框架和构建链。无计时、分数或输赢。

## 状态与输入

- URL：仍为 `#room?activity=peel`；关闭、Esc、浏览器后退回房间并恢复焦点。内部任务为短暂状态，不写路由或本地存储。
- 掌机仍为房间入口；现有“使用说明”提供同名文字入口，名称从 ACTIVITY_HOTSPOTS 派生。减少动态或无法环视时可通过该入口进入，关闭任务后焦点返回使用说明按钮。顶部三个业务入口保持不变。
- `track`：按住 W/S 前后走、A/D 左右平移（方向键同义），松键停止；按住空白街景拖动鼠标调整水平和俯仰视角，移动朝向随视角变化。也可点击当前路标或聚焦后按 Enter 自动前往。靠近下一路标 1.35 个场景单位内才推进，三段依次抵达，不允许跳过未到达节点。
- `peel`：抓住两张营销外壳向两侧甩开；短拖动、取消拖动不计完成。键盘 Enter/Space 有等价“摘下”操作。
- `trial`：可在七天轨道、已有替代、目标权衡之间切换；商品可拖放，也可先选商品再按目标按钮。至少完成一个装置后可前往传送带；可继续尝试其余装置。不把试用选择送入评分或写入订单行为字段。
- `deliver`：把完整商品推入冷静传送带，或选择仍然想要并离开。传送动作只展示确认单。
- `review`：展示可编辑名称、金额和用途，点击“确认保存冷静单”才调用既有 createOrder。手势不能确认保存；不产生真实购买、确认省下或目标进度。
- `done`：以 app.js 返回的真实订单事实渲染青色道路和熄灭广告；再次进入时从订单派生已有冷静单，避免重复创建；存储失败须提示临时保存和刷新丢失风险。

第一条任务固定耳机与两层信号，同一输入结果可复现。商品池示例不进入业务存储；用户在确认单主动采纳/编辑为本人想买的商品后才生成个人记录。已有同名同金额冷静单直接复用。试玩退出不写任何订单。确认单没有询问实际购买动机，因此原因使用不产生评分证据的“其他”，不沿用商品池的“被种草”，也不写入试用动作或行为信号。

普通输入：手动行走速度为 4.8 个场景单位/秒，斜向归一化；单帧按最多 60ms 移动，街道两侧和信号门有边界。鼠标水平角限制为 ±1.25 弧度、俯仰为 0.66–1.1 弧度，不使用指针锁定。按键可中途接管自动前往，保留当前位置并取消旧抵达事件；再次点击路标切回自动移动。失焦、隐藏、指针取消、关闭任务、切换手势、进入工作台阶段均清除按键。商品输入框不接收移动快捷键。减少动态和静态回退下使用点击路标、W / ↑ 或 Tab / Enter 前进，不连续行走或转镜。移动设备保留点击路标和物件触摸拖放。

手势：主动开启后本地识别，指尖指向场景目标、捏合或握拳抓取、移走甩开/拖动/推送、松开放下；这些动作仅修改本次任务状态。只有路标支持停留一秒出发。丢手取消抓取并暂停，鼠标、触控随时接管。手势不控制连续镜头，不自动提交确认单。摄像头识别失败保留普通输入并撤销按钮激活状态。

## 渲染、布局与回退

街区使用深蓝灰底、暖琥珀广告、青色冷静光路；实体建筑、管线、路标和探测器建立空间层次。界面仅保留顶部任务名、阶段进度和当前操作提示，主要操作位于场景内。所有操作都有 DOM 控件与可见焦点，触控目标至少 44px。

按需加载场景模块；DPR 最大 1.5，慢帧降低至 1。隐藏标签页和关闭时停止 rAF，释放几何、材质和纹理。减少动态时移动和镜头立即到位，取消循环动画。Three.js 加载失败或 WebGL 失效时使用原创 CSS 街道与静态商品，并保留完整任务操作。
