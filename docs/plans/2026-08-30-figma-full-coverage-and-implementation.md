### 3.2.1 规则人格与 Figma 卡面的双层合同

分享卡采用“双层命名”，但不采用双重评分：

- `personality-scoring.js` 输出的九类主人格与“欲望观察员”是唯一权威人格，决定分数、置信度、证据和建议。
- `persona-presentations.js` 只根据同一份聚合结果选择 Figma 趣味卡面、插图、配色和标签；卡面变化不得回写或覆盖主人格。
- 研究主权者映射“省钱幻想家 / 购物车钉子户”，优惠精算师映射“价格真香党 / 限时优惠上头客”，种草冲锋手映射“冲动型猎人 / 心动采购官”，氛围疗愈师映射“氛围感收割机 / 奖励性消费家 / 快乐外卖党 / 奶茶续命人”。
- 社交共鸣者映射“精致生活玩家 / 快乐批发商”，微观成就家映射“兴趣投入家”，极简缓冲者映射“购物车钉子户 / 冷静幸存者”，收藏囤货派映射“囤货型选手”，平衡洞察者映射“钱包过山车玩家 / 翻脸横跳派”，欲望观察员映射“钱包随心侠”。
- “夜间心动客”和“小额无感王”只在本地聚合的结构化证据达到门槛时覆盖视觉卡面：当前周期至少 3 笔同类记录且占比至少 60%。这两个信号仅选择插图与配色，不改变规则人格；没有证据时继续使用对应主人格的默认卡面。
- 原稿中涉及收入、年龄、羞辱或道德优越的名称仅保留在源码追溯字段；用户可见名称分别改为“精致生活玩家”“快乐批发商”“钱包随心侠”“冷静幸存者”“夜间心动客”“兴趣投入家”，并将“买买买狂人”改为“心动采购官”。

## 6. 不能被视觉稿覆盖的产品事实

1. 产品展示名固定为“让你花个爽！”，技术短名 `spree` 不出现在用户文案中。
2. 产品是消费冲动缓冲器，不接银行卡、不真实下单、不真实支付、不验证存款到账。
3. 订单状态仅允许：`冷静中 → 幸好没买`、`冷静中 → 最终购买`、`幸好没买 ↔ 最终购买`、任意状态经确认后删除。
4. “冷静中”和“最终购买”都不计入确认省下或目标进度。
5. 评分、人格、置信度、金额、次数和目标进度由本地版本化规则唯一决定；图像、动效、分享卡和在线解释都不能改写这些事实。
6. 默认数据保存在当前浏览器；LocalStorage 不可用时必须提示可能丢失，不能假装已保存。

### 当前阻塞与产品合同冲突

1. Make 的 17 个原始图像二进制仍因权限错误无法逐文件打开；这项不能写成完成。

4. 设计稿商品图进入公开站点前仍需确认素材授权；本轮已将可识别商标或第三方角色风险较高的商品图换成中性本地 SVG，但审阅附录中标记为需确认来源的素材仍不能自动获得发布授权。
